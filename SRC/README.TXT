WYPA
++++++++++

+
a little tool to paint pictures on DOS/FreeDOS
Almost entirely done by Stefan Mader of Puls4r except some libraries
used (see STL and IMGUI).

+
This program was coded within four weeks for the core part and may have
some bugs left. If you find some bugs don't hesitate to write me on Facebook.

+
Actually this program was only done because there was no propper solution
to paint pictures (for me) on DOS, so to say it's an Puls4r "InHouse" tool.
But it's completely open source.
Almost all used libraries have a MIT or Public Domain license aswell as the
entire program is written under the "most permissive" MIT license, for your
pleasure. You may do anything you want with it, so to say.
But please don't say you have coded all that stuff.

+
I didn't do much with it till now, if I have tested and used it for a
longer time, maybe the currently left bugs will already have vanished.

+
I wan't to make games some day again, but this time using FreeDOS so
this program and Swife are two programs that may be useful in the future
for creating games (on FreeDOS).

+
Puls4r is a 8-bit "Studio" for games for the C64 and C16/Plus4 but I really
like to add DOS games to the portfolio.

+
Have a nice day and all the best from Puls4r.
